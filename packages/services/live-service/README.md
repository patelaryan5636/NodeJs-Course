# Live Service

Live streaming and real-time video service.

## Features

- Live streaming capabilities
- Real-time video handling
- Broadcast management
- Live API endpoints

## Files

- **Live.js** - Core live streaming service
- **Live-Api.js** - API endpoints for live features

## Running

```bash
node Live.js
# or
node Live-Api.js
```

## Use Cases

- Live video streaming
- Webinars
- Live events broadcasting
- Real-time video feeds

## Dependencies

- express
- (Streaming libraries as needed)
