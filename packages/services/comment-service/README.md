# Comment Service

Service for managing comments, ratings, likes, and subscriptions.

## Features

- Comment CRUD operations
- Comment rating system
- Like functionality
- Subscribe functionality
- User interaction tracking

## Files

- **Comment-api.js** - Comment management API
- **Comment-rating.js** - Rating system for comments
- **Like-subscribe-api.js** - Like and subscribe functionality

## Running

Each service can be run independently:

```bash
node Comment-api.js
node Comment-rating.js
node Like-subscribe-api.js
```

## Use Cases

- Social media platforms
- Blog comment systems
- Video platform interactions
- Community engagement features
