# Chat Service

Real-time chat server with WebSocket support.

## Features

- Real-time messaging
- WebSocket connections
- Chat room support
- Message broadcasting

## Files

- **chat-server.js** - WebSocket-based chat server

## Running

```bash
node chat-server.js
```

## Use Cases

- Real-time chat applications
- Messaging platforms
- Customer support chat
- Collaborative tools

## Dependencies

- express
- socket.io (or WebSocket)

## Architecture

Implements WebSocket protocol for bidirectional communication between clients and server.
