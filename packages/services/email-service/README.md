# Email Service

SMTP email forwarding and notification service.

## Features

- SMTP email forwarding
- Email sending
- Email notifications
- Mail relay

## Files

- **Smtp-forward.js** - SMTP forwarding service

## Running

```bash
node Smtp-forward.js
```

## Use Cases

- Transactional emails
- Email notifications
- Contact form handling
- Email forwarding

## Dependencies

- express
- nodemailer (or SMTP library)

## Configuration

Configure SMTP settings:
- SMTP host
- SMTP port
- Authentication credentials
- TLS/SSL settings
