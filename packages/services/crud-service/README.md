# CRUD Service

Basic Create, Read, Update, Delete operations template.

## Features

- Create resources
- Read/List resources
- Update resources
- Delete resources

## Files

- **Crud.js** - Basic CRUD operations implementation

## Running

```bash
node Crud.js
```

## API Endpoints

Standard REST endpoints:
- `POST /` - Create
- `GET /` - List all
- `GET /:id` - Get one
- `PUT /:id` - Update
- `DELETE /:id` - Delete

## Use Cases

- Template for new services
- Learning REST API basics
- Quick prototyping
- Database operation examples

## Dependencies

- express

## Purpose

This service serves as a template and learning example for implementing standard CRUD operations in Node.js applications.
