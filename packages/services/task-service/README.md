# Task Service

Task management and tracking API.

## Features

- Task creation
- Task tracking
- Status management
- Task API endpoints

## Files

- **Task-api.js** - Task management API

## Running

```bash
node Task-api.js
```

## API Endpoints

- Create task
- Get tasks
- Update task
- Delete task
- Mark task complete

## Use Cases

- Todo applications
- Project management
- Issue tracking
- Workflow management

## Dependencies

- express
