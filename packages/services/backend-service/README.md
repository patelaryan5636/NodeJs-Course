# Backend Service

Main backend service with comprehensive API endpoints and file upload capabilities.

## Features

- User authentication with JWT
- File upload with multer
- In-memory database simulation
- RESTful API design
- Request logging middleware

## Files

- **Backend.js** - Main backend application server

## Running

```bash
node Backend.js
```

## API Endpoints

- Authentication routes
- File upload routes
- CRUD operations
- Protected endpoints

## Dependencies

- express
- multer
- jsonwebtoken
- crypto

## Environment Variables

- `PORT` - Server port (default: 3000)
- `JWT_SECRET` - Secret for JWT signing

## Port

Default: 3000
